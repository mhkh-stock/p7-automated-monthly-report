# P7 data

`data/raw/sales_SAMPLE.csv` — 560 SAMPLE order lines, Jul–Sep 2026,
fictional shop "CityMart". Generated by `src/generate_sample_data.py`
(seed 42, deterministic). Columns: order_id, date, product, category,
qty, unit_price_pkr, amount_pkr (qty × unit price). No real business's
sales are involved.

## Data dictionary

| Column | Type | Example | Notes |
|---|---|---|---|
| `order_id` | text, unique | `ORD-1001` | One row per order line; 560 unique values |
| `date` | date, `YYYY-MM-DD` | `2026-09-07` | Days 1–28 only (generator range); months Jul–Sep 2026 |
| `product` | text | `Office Chair` | 10 products across 4 categories |
| `category` | text | `Furniture` | Electronics, Furniture, Kitchen, Stationery |
| `qty` | integer 1–3 | `2` | Units on the line |
| `unit_price_pkr` | integer (PKR) | `18900` | Fixed per product (see `src/generate_sample_data.py`) |
| `amount_pkr` | integer (PKR) | `37800` | Always `qty × unit_price_pkr` |
