# P7 data

`data/raw/sales_SAMPLE.csv` — 560 SAMPLE order lines, Jul–Sep 2026,
fictional shop "CityMart". Generated by `src/generate_sample_data.py`
(seed 42, deterministic). Columns: order_id, date, product, category,
qty, unit_price_pkr, amount_pkr (qty × unit price). No real business's
sales are involved.
