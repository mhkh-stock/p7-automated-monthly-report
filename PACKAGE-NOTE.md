# P7 — Package Note (Fiverr-ready)

**Gig title:** I will build your automated monthly sales report that updates itself

**What the client gets:** a monthly report that rebuilds itself from
their sales lines — a Summary sheet with revenue, month-on-month
growth, orders and average order value, a category chart, and a
Monthly Trend sheet — in Excel or Google Sheets, whichever they use.
No more rebuilding the same report by hand every month.

## Tiers (Hashir's band)

| Tier | Price | Delivery | Includes |
|---|---|---|---|
| Basic | $20 | 2 days | One month's report in Excel: Data + Summary + charts, all totals as live formulas |
| Standard | $65 | 3 days | 3 months of history + Monthly Trend sheet, Google Sheets version with the automation script, setup guide so next month builds itself |
| Premium | $140 | 5 days | 12 months of history, automated monthly trigger (report builds on the 1st), category + product breakdowns, reusable builder script for the client's own future months, 1 revision round |

**What's NOT included:** cleaning a messy source file first (that's
the P2 data-cleaning service — quoted together if needed); a Power BI
dashboard (that's the P3 service); connecting live POS/shop
integrations (quoted on seeing the system).

**Delivery time note:** counts from the day the client uploads their
sales file, not from order placement.

**Proof this service works:** this repo's sample — 560 lines across
Jul–Sep 2026, Sep revenue PKR 2,862,500 at +15.82% month-on-month,
16 automated checks passing, and a Google Apps Script that rebuilds
the same report inside Sheets. The sample workbook is the demo the
buyer sees before ordering.
